# Victor Learnings

Purpose: reusable lessons proven by evidence. Each lesson must state trigger, lesson, and operating consequence.

## L-001 — Activity is not outcome
Trigger: repeated autonomous cycles produced files/readiness artifacts while verified revenue remained zero.
Lesson: task completion and system activity must never be promoted to commercial success.
Consequence: prioritize the closest measurable revenue/conversion action and require business-outcome evidence for success claims.

## L-002 — Unknown telemetry is not zero
Trigger: Instagram engagement fields were null while logic proposed "if no clicks" actions.
Lesson: missing observation cannot be interpreted as negative performance.
Consequence: null/absent metrics = UNKNOWN/METRICS_UNAVAILABLE. A/B or route changes based on zero clicks require a real collector and completed observation window.

## L-003 — Autonomous agents need sensors
Trigger: RIO could publish and plan but lacked a collector for engagement/click signals.
Lesson: an autonomous decision loop without reliable observation becomes a blind loop.
Consequence: every optimization loop must define its source-of-truth telemetry before using the metric in decisions.

## L-004 — Victor should steer, RIO should execute
Trigger: RIO autonomously completed useful commercial work but could drift into pillar/readiness rotation.
Lesson: central strategy and local execution should be separated.
Consequence: Victor owns direction/replanning; RIO retains execution autonomy and returns evidence.
